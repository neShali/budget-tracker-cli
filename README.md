# Budget Tracker CLI

Консольное приложение для управления личными финансами:
- создание/удаление/переименование счетов
- добавление/удаление транзакций (доход/расход)
- просмотр баланса и истории
- экспорт транзакций счета в CSV

## Требования
- Node.js 18+ (лучше 20+)
- npm

## Установка
```bash
npm i
````

## Запуск (dev)

```bash
npm run dev
```

## Проверка типов

```bash
npm run typecheck
```

## Сборка и запуск

```bash
npm run build
npm start
```

## Экспорт в CSV

Экспорт создаёт `.csv` файл в текущей папке, откуда запущено приложение.
Если имя файла не указано — будет использовано автоматическое.
